For learning and research

This model has no “normal” class and cannot tell whether a fracture is present. It will assign fracture-type scores to any image. Scores are not clinical probabilities; a qualified clinician must interpret X-rays.

Behind the interpretation

Small model.
Visible evidence.

EfficientNet-B0 transfers visual features learned on ImageNet to twelve fracture categories. The notebook documents the data audit, training curves, per-class results and mistakes.

Validation selects the checkpoint; the supplied test split is evaluated afterward. Exact pixel duplicates are removed. Patient identities are unavailable, so patient-level independence is unverified.

The original notebook’s 50.29% peak was selected using the test folder. It is not a comparable untouched-test baseline.
