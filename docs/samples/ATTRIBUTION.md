# Sample X-rays

Source: Shyam Gupta, [Bone Fracture Split Classification, version 1](https://www.kaggle.com/datasets/shyamgupta196/bone-fracture-split-classification).

Kaggle's dataset listing declares CC0: Public Domain. See the repository's DATA_SOURCES.md for provenance limitations.

One image per class comes from the cleaned held-out test split. Seed 42 is used with five visually reviewed replacements for non-radiographs or branded stock imagery. Selection does not depend on whether the model predicts the sample correctly. Source pixel hashes and the selection rule are recorded in samples.json and the notebook. These are demonstration inputs, not an independent new test set.
